# pair-wise-yf-54 博物馆展品点交与布展条件核验

## 源提示词摘要
策展人、保管员、布展负责人和借展方从到场点交、环境条件检查、安装位置确认到闭展归还共同处理展品。系统记录条件、附件、风险等级、照片说明、处理意见和签字结果，差异项未解决时不能进入下一阶段，并支持大量展品与断网暂存。

## 技术栈
Vue 3 + TypeScript + Vite + Vuetify + Pinia + Vue Router + Axios + VueUse + VeeValidate + Zod + Vue I18n。

## 已实现闭环
- 展品、环境检查、差异项三类业务对象。
- 到场点交、布展核验、闭展归还的分阶段签字与推进门禁。
- 未解决差异阻断流转，可单独确认解决。
- `v-virtual-scroll` 大列表、离线队列提示、手动确认同步。
- localStorage 持久化。

## 离线续作（网络不稳时按字段合并）
点交现场断网时，改动不再整单覆盖，而是按字段留存为离线批次（`off-xxx`）：
- 每条批次记录**改动字段**、**before/after**、**设备号**与**基线版本**。
- 回网后逐字段合并：两边改到**不同字段**则两版都留下；**同一字段两边都改**则标记为冲突，保留离线版与服务端版两版，需人工确认采用哪版后才写入。
- 合并失败（如展品已删除）批次不丢，按**离线编号**重试即可。
- 提供「模拟对端设备改动」，可在一台设备上演示借展方另一台设备回网后的字段合并。

## 签字绑定内容
- 签字绑定当时的展品内容（对环境、附件、差异项计算哈希）与展品版本。
- 环境、附件或差异项在签字后有改动（版本或哈希变化）→ 签字立即失效，须重新签字才能推进。
- 保管员用本机设备、借展方用借展方设备号签字；两方在同一设备完成签字判定为**越权代签**。

## 推进与归还门禁
存在以下任一情况时，推进下一阶段与确认归还都会被挡住并列出原因：
- 差异项未解决；
- 存在未确认的字段冲突；
- 有未合并的离线批次；
- 缺少保管员或借展方签字；
- 签字版本对不上（内容/版本变更后失效）；
- 借展方越权替保管员签字（两方设备号相同）。

## 升级兼容
旧版本地数据（签字为 `string[]`、无版本/附件/批次）加载时自动迁移：补全设备号、版本与内容哈希，并按**现有签字与阶段**补一条来源记录（`source` 字段），旧数据不丢失、可继续使用。
